If you pay or credit amounts such as interest, dividends or pensions to non-residents of Canada, you report them on the NR4 information return: an NR4 slip for each recipient and an NR4 Summary. Those amounts are generally subject to Part XIII non-resident tax. The return is due no later than March 31 following the calendar year. What an NR4 XML file is

An NR4 XML file is one <Submission> with two parts:

  • T619 transmitter record. The wrapper that says who is sending the file: the transmitter's CRA account number (usually the 15-character business number), a Submission Reference ID, a contact name, phone and email, and the language.
  • NR4 return. One <NR4Slip> per non-resident recipient, followed by one <NR4Summary> with the payer's details and the totals for every slip in the file.

You upload the file to IFT, which checks it against CRA's XML schema. Electronic filing is required once you file more than 5 slips of a type in a calendar year. Below that, it is optional but still accepted.

CRA XML specifications in plain terms

TaxXML follows CRA's 2027 package, schema 1-27-1 (T619 2027V1 for the transmitter record and NR4 2027V1 for the return), for files you make from December 22, 2026; CRA accepts it from January 11, 2027, normally for the 2026 tax year. Files made before then follow schema 1-26-3 (T619 2026 and NR4 2026V3), which CRA accepts until December 22, 2026. The two differ for NR4: a 2027 slip must carry the recipient's Canadian tax identification number (Box 13), and a 2026 slip must not. The elements you will see most:

  • nr_acct_nbr: the payer's non-resident account number, 3 letters and 6 digits, for example NRA123456. The same number goes on the summary and every slip.
  • RCPNT_NM or ENTPRS_NM: the recipient's name. Individuals and joint accounts use RCPNT_NM; corporations and everyone else use ENTPRS_NM.
  • rcpnt_tcd: recipient type. 1 individual, 2 joint account, 3 corporation, 4 other (association, trust, partnership), 5 government or international organization.
  • tx_cntry_cd, fssn_nbr: the recipient's 3-letter country of tax residence (Box 12) and their foreign tax identification number (Box 30 on 2027 slips; Box 13 before).
  • CIN, new in schema 1-27-1: the recipient's Canadian tax identification number (Box 13): a SIN, TTN or ITN (sin_ttn_itn), a business number (bn) or a trust account number (trust). When the recipient hasn't provided one, CRA says to enter <sin_ttn_itn>000000000</sin_ttn_itn>; TaxXML does that for a blank or missing Canadian Tax ID column.
  • RCPNT_ADDR: a foreign address, so it uses ste_cd and fgn_pstl_cd instead of a province and postal code.
  • inc_1_tcd, crcy_1_cd: the income code (Box 14) and currency code (Box 15).
  • NR4_AMT: gross income (Box 16) and non-resident tax withheld (Box 17).
  • tx_xmpt_1_cd: the exemption code (Box 18), when one applies.
  • rpt_tcd: report type. O for original, A for amendment, C for cancel on a slip. The summary takes O or A only.

The full rules are on CRA's site: XML specifications for information returns and the T619 2027 specification.

Common reasons CRA rejects an NR4 XML file

  • Country codes with 2 letters. NR4 needs 3-letter codes, like USA or DEU, not DE. TaxXML converts US and CA for you and flags any other code that isn't 3 letters.
  • Empty optional tags. CRA rejects files that contain empty optional tags: a tag with nothing in it, like <fgn_pstl_cd/>, gets the file rejected. Optional fields with no value must be left out entirely. TaxXML leaves out blank optional fields. Don't type "N/A" or a space to fill a cell.
  • Non-resident account number in the wrong format. It is 3 letters and 6 digits, and it must be the same on the summary and every slip.
  • Income codes that lost their leading zero. Income codes are 2 digits, like 02 or 06. Excel turns 06 into 6 unless the column is formatted as Text. TaxXML puts the zero back and flags any code that isn't 2 digits.
  • Reused Submission Reference ID. Every file needs a new one. TaxXML bumps it for you (A to B) when you come back to resubmit.
  • A cancel code on the summary. The NR4 summary has no C. Cancelled slips go under an amended (A) summary.

NR4 XML questions

When is the NR4 return due?

No later than March 31 following the calendar year in which the amounts were paid or credited. Check CRA's NR4 guide if you file for an estate or trust.

Do I have to file NR4 slips electronically?

Yes, if you file more than 5 NR4 slips for a calendar year. CRA requires electronic filing above that number. Internet File Transfer with an XML file is one of the accepted ways.

Which CRA XML schema does TaxXML use for NR4?

For files made from December 22, 2026: CRA XML schema 1-27-1, T619 2027V1 and NR4 2027V1, which CRA accepts from January 11, 2027. Files made before then use schema 1-26-3 (T619 2026 and NR4 2026V3), accepted until December 22, 2026. It also follows CRA's rule that empty optional tags must be left out, because IFT rejects them.

Is my data uploaded anywhere?

No. The spreadsheet is read and the XML is built in your browser. TaxXML does not send the file to a server or to CRA. You upload it to Internet File Transfer yourself. See Privacy.

How do I cancel an NR4 slip CRA already accepted?

The NR4 summary only accepts Original (O) or Amendment (A). Send the cancelled slip under an amended summary, with a new Submission Reference ID. TaxXML does this for you when you choose Cancel.
