Guides

Plain-English guides to the CRA XML format for each return TaxXML converts, and sample files that validate against the CRA XML schema.

  • T4 XML guide
    Turn a T4 payroll spreadsheet into CRA XML for Internet File Transfer. Free, runs in your browser. Plain-English guide to the CRA XML schema and common rejects.
  • NR4 XML guide
    Turn an NR4 spreadsheet of non-resident payments into CRA XML for Internet File Transfer. Free, runs in your browser. Plain-English guide to the NR4 XML schema.
  • T5018 XML guide
    Turn a T5018 subcontractor payments spreadsheet into CRA XML for Internet File Transfer. Free, runs in your browser. Plain-English guide to the T5018 schema.
  • T1204 XML guide
    Turn a T1204 government service contract spreadsheet into CRA XML for Internet File Transfer. Free, runs in your browser. Plain-English guide to the schema.
  • Sample CRA XML files
    Sample CRA XML files for T4, NR4, T5018 and T1204 information returns that validate against the CRA XML schema, with a plain-English element reference.
